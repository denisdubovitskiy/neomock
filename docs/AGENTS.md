# Документация neomock

MkDocs: исходники — эта директория, конфиг — `../mkdocs.yml`.
Этот файл не публикуется (исключён через `exclude_docs`).

## Карта страниц

| Страница | Тип (Diátaxis) | Содержимое |
|----------|----------------|------------|
| index.md | Overview | Что это, какие боли решает, ключевые решения, статус компонентов |
| usage.md | Reference | DSL сгенерированного мока (When/Then/кардинальность/Run/история/Verify), режимы ошибок, API пакета `neomock` |
| configuration.md | Reference | Файл конфига: обнаружение, схема, все ключи, шаблоны имён, приоритеты слоёв, валидация |
| cli.md | Reference | Команды init/generate/check/explain/migrate/version, go:generate режимы А/Б, коды возврата |
| examples.md | How-to | Шесть сценариев размещения моков (stdlib/внешние/свой проект/inpackage/текущая директория/отдельный пакет) + частные случаи |
| architecture.md | Explanation | Конвейер генерации (mermaid), путь вызова, инварианты, обоснования решений, границы v1 |
| development.md | How-to | Команды сборки/тестов, golden-регенерация, границы репозитория, договорённости процесса |

## Куда класть новую информацию

- Новая сущность DSL или API рантайма → `usage.md` (+ таблица «Пакет рантайма»).
- Новый ключ конфигурации, шаблонная переменная, приоритет слоёв → `configuration.md`.
- Новая команда CLI или флаг go:generate → `cli.md`.
- Новый сценарий использования/размещения мока → `examples.md`.
- Обоснование решения — в `architecture.md`, статус — в таблице `index.md`.
- Новое решение по дизайну → краткое «почему» → `architecture.md`.
- Новый make-таргет / изменение команд → `development.md` и корневой `AGENTS.md`.

## Локальные конвенции

- Язык — русский; примеры кода — в стиле Store/Get.
- Новая страница → `nav` в `../mkdocs.yml` ровно один раз.
- Ссылки между страницами — относительные пути к `.md`; проверяются strict-сборкой.
- Ссылки на корневые файлы (`CHANGELOG.md`) — именем в код-спане, без
  ссылки: файлы вне `docs/`, MkDocs их не перепишет.
- Диаграммы — mermaid; скрипт `assets/js/vendor/mermaid@11.min.js` (вендорён,
  CDN запрещён). Тип диаграммы: flowchart — компоненты, sequenceDiagram —
  путь вызова.
- Статусы компонентов не дублировать: таблица статуса — только в `index.md`.

## Проверка

- Сборка: `make docs-build` (= `poetry run mkdocs build --strict`).
- Рендер: `make docs-serve` → http://localhost:8000.
